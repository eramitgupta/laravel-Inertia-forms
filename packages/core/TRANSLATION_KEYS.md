# Translation keys

Every piece of text the built-in components render themselves, with its English default. This list is the contract for the React, Vue and Svelte packages: each package renders the same key in the same place and adds no hard-coded English.

- Source of truth: `defaultTranslations` in [`src/i18n.ts`](src/i18n.ts) (130 keys). Update this file when a key is added or renamed.
- Parameters use Laravel-style tokens: `:name` as is, `:Name` with the first letter upper-cased, `:NAME` upper-cased. Longer parameter names are replaced first. A value can also be a function `(params) => string`.
- A key with no translation falls back to the English default, then to the key itself.
- Numbers are passed as numbers (`:count`, `:number`, `:current`, `:total`, `:day`, `:year`), so function values can format them.
- Text with elements inside (`file_upload_drop_prompt`, `composer_hint`) is rendered with core `translateParts(key, slots)`, which returns strings and `{ slot }` markers in the translated order.
- "core `fn()`" means a shared helper in `packages/core/src` already calls `translate()`; framework packages call the helper instead of the key.

## Framework integration (what Vue and Svelte mirror)

- Export from the package index: `setTranslations`, `resetTranslations`, `getTranslations`, `translate`, `translateParts`, `subscribeTranslations`, `translationsVersion`, `defaultTranslations`, and the types `TranslationValue`, `TranslationParams`, `TranslationKey`, `Translations`, `TranslationPart`.
- Re-render on change: React calls `useTranslate()` (`useSyncExternalStore(subscribeTranslations, translationsVersion)`) in every component that renders text, including `Form`. Vue and Svelte need an equivalent reactive version counter (for example a `shallowRef` or store bumped from `subscribeTranslations`) read during each component's render, so text updates after `setTranslations()`.
- Laravel now sends `null` unless the developer sets a label: `wizard.nextLabel` / `wizard.backLabel` (use `wizardNextLabel()` / `wizardBackLabel()`), Blocks and Repeater `addActionLabel` (use `builderAddLabel()`), KeyValue `keyLabel` / `valueLabel` / `addActionLabel` (use `keyValueLabels()`), Composer `sendLabel` (use `composerSendLabel()`). The types in `src/types.ts` are nullable.
- Calendar text comes from these keys, not `Intl`: `weekdayLabels(firstDayOfWeek)`, `monthLabel(month)` and `formatDisplayDate(value)` no longer take a locale argument. Use `calendarDayLabel(iso)` instead of `Date#toDateString()` for the day `aria-label`.

## Not translated on purpose

- The `*` required marker (`FieldWrapper`, `Checkbox`): a symbol hidden from screen readers.
- `--:--` / `--:--:--` (TimePicker placeholder) and `#000000` (ColorPicker hex placeholder): format examples, not words.
- `…` (open range end) and the `·` / `, ` separators in `fileUploadHint()`: punctuation. Translate `date_range` to change the range layout.
- Block menu icon text (`block.icon`) and swatch `aria-label`s (the hex value): data.
- Field labels, help, placeholders, option labels, step legends and other copy sent by Laravel: app-owned, translated in PHP with `__()`.
- `console.warn` messages and thrown `Error`s: developer-facing.
